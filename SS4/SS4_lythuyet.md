Ôn tập kiến thức

Buổi 3: 

- Toán tử:

  - Số học: + - * / %
  - Gán: =
  - So sánh: <, >, ==, <=, >=, ===
  - Logic: &&, ||, !
    - && (and): Tìm kiếm false, nếu không có thì trả về True
    - || (or): Tìm kiếm True, nếu không có thì trả về False
    - ! (not): != (khác),
- Câu điều kiện

  - Thiếu: if (condition){ ...}
  - đủ: if (condition){} else {}
  - bổ sung: if - else if - else
- Nhập dữ liệu từ bàn phím: prompt("câu gợi ý người dùng")

  - lưu trữ dữ liệu vừa nhập vào biến theo cú pháp: let x = prompt("")
- Ép kiểu dữ liệu:

  - string -> Number: Number(x)
  - Number -> String: String(x)
- Vòng lặp:

  - for: vòng lặp biết trước số lần lặp
  - while: vòng lặp kiểm tra điều kiện -> thực hiện.
  - do while: vòng lặp thực hiện lệnh trước -> kiểm tra điều kiện sau.
